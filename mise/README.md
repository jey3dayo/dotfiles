# mise Configuration Files

`mise/` は共通・環境別 config、helper scripts、タスク定義を格納する。各タスクの現在の一覧と詳細は `mise tasks` / `mise tasks info <task>` で確認する。

詳しい説明は各ガイドを参照してください。

- [docs/tools/mise.md](../docs/tools/mise.md) - 環境選択、設定境界、タスクの使い分け
- [docs/tools/mise-tasks.md](../docs/tools/mise-tasks.md) - タスクの実行影響、安全上の注意、調べ方
- [docs/tools/mise-config.md](../docs/tools/mise-config.md) - backend と version pin の理由
- [docs/setup.md](../docs/setup.md#package-management-philosophy) - mise / Homebrew / Chocolatey の責務分離
