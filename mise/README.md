# mise Configuration Files

`mise/` は環境別 config（`config.*.toml` / `entry.*.toml`）、helper scripts（`lib/`）、タスク定義（`tasks/`, `local-tasks/`）を格納する。

詳細は以下を正本として参照する:

- [docs/tools/mise.md](../docs/tools/mise.md) - 設定構成、環境検出、ディレクトリレイアウト、Homebrew との使い分け
- [docs/tools/mise-tasks.md](../docs/tools/mise-tasks.md) - 全タスク一覧と実行影響の分類
- [docs/tools/mise-config.md](../docs/tools/mise-config.md) - ツールカテゴリの詳細
