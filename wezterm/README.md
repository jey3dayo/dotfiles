エントリポイントは [`wezterm.lua`](wezterm.lua)（`config.lua` を require）。

詳細な設定構造・キーバインド・トラブルシューティングは [`docs/tools/wezterm.md`](../docs/tools/wezterm.md) を正本として参照。Claude向けの凝縮版ルールは [`.claude/rules/tools/wezterm.md`](../.claude/rules/tools/wezterm.md)。
