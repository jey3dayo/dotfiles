# WezTerm Configuration

GPU 加速に対応した Lua ベースのモジュラーターミナル設定です（Gruvbox テーマ、tmux スタイルのリーダーキー `Ctrl+x`）。

エントリポイントは [`wezterm.lua`](wezterm.lua)（`config.lua` を require）です。

詳細な設定構造・キーバインド・トラブルシューティングは [`docs/tools/wezterm.md`](../docs/tools/wezterm.md) を正本として参照してください。Claude 向けの短いルールは [`.claude/rules/tools/wezterm.md`](../.claude/rules/tools/wezterm.md) にあります。
