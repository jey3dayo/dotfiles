# Neovim Configuration

Comma-leader、lazy.nvim ベースのモダンなLua設定。blink.cmp による補完、mini.nvim を中心とした編集面、Mason 管理の LSP スタックを組み合わせている。

エントリポイントは [`init.lua`](init.lua)。

詳細な設定構造・起動性能・LSP/プラグイン構成・キーバインドは [`docs/tools/nvim.md`](../docs/tools/nvim.md)（[検証](../docs/tools/nvim.md#検証)含む）を正本として参照。Claude向けの凝縮版ルールは [`.claude/rules/tools/nvim.md`](../.claude/rules/tools/nvim.md)。
