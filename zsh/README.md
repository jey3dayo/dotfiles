# Zsh Configuration

高速な対話シェル起動を優先した最小構成の Zsh 設定です。エントリポイント、`lib/<category>/`、`completions/`、`sheldon/`、`bin/` を中心に構成しています。

エントリポイントは [`.zshenv`](.zshenv) / [`.zshrc`](.zshrc) です。

詳細な構成・ロード順・キーバインド・起動性能は [`docs/tools/zsh.md`](../docs/tools/zsh.md)（[検証](../docs/tools/zsh.md#検証)を含む）を正本として参照してください。Claude 向けの短いルールは [`.claude/rules/tools/zsh.md`](../.claude/rules/tools/zsh.md) にあります。
