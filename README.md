# Personal Dotfiles

Personal development environment configuration for macOS, Linux/WSL2, and Windows. Most setup is managed with `mise bootstrap`.

## Key paths

- `mise/` — bootstrap, tool, and task configuration
- `zsh/`, `nvim/`, `wezterm/`, `git/` — shell, editor, terminal, and Git configuration
- `docs/` — setup, operational, and tool guides
